# Claude Code Skills 超やさしいマニュアル

Claude Codeの7つのSkillについて、導入から使い方、具体例までを図解とアニメーションで解説する、初心者向けのマルチページサイトです。

## ページ構成

- `index.html` トップ（Skillとは、導入のメリット）
- `install.html` 導入ガイド（ダウンロードから認識の確認まで）
- `skills.html` 7つのSkillの一覧と選び方
- `skills/*.html` 各Skillの詳細ページ（7ページ）
- `start.html` 使い始め方（架空の講座で1周する流れ、注意点）
- `glossary.html` 用語集
- `assets/style.css` `assets/app.js` 共通のCSSとJavaScript

## 公開方法（GitHub Pages）

1. GitHubで新しいリポジトリを作成
2. このフォルダーの中身をすべてアップロード（`index.html` がルートに来るように）
3. Settings > Pages を開く
4. Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして Save
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
